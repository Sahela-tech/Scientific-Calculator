# 🧮 Simple Scientific Calculator

A sleek, responsive, and easy-to-use web-based Scientific Calculator built with pure HTML5, CSS3, and modern JavaScript (ES6). Designed with a clean dark-mode user interface.

## ✨ Features

- **Basic Arithmetic**: Addition, Subtraction, Multiplication, Division.
- **Scientific Functions**:
  - Trigonometric operations: `sin`, `cos`, `tan`
  - Logarithmic operations: `log` (base 10)
  - Square Root (`√`) and Exponentiation ($x^y$)
- **Mathematical Constants**: Pi ($\pi$) and Euler's Number ($e$).
- **User Experience**:
  - Clear (`AC`) and Backspace (`DEL`) functionality.
  - Bracket support for complex mathematical expressions.
  - Smooth hover effects and dark theme UI.
  - Mobile & desktop responsive layout.
